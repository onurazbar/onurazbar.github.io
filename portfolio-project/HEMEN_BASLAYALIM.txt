⚙️ AYARLAR:

Dosya Yolları Doğru mu?
───────────────────────
HTML'de şu satırları kontrol edin:
<link rel="stylesheet" href="css/style.css">
<script src="js/script.js"></script>

Renk Başlıkları:
────────────────
css/style.css dosyasında :root { } bölümü tüm renkleri içerir.
Buradan kolayca değiştirilebilir.

Font:
─────
Google Fonts'tan "Poppins" kullanıyoruz.
Değiştirmek için:
1. Google Fonts'a gidin
2. Yeni font seçin
3. HTML <head> bölümünde link değiştirin
4. css/style.css 'de font-family değiştirin

❓ Ssikça SORULAN SORULAR:

S: Form çalışmıyor?
C: Form yerel olarak test edilir. Dağıtırken Formspree
   veya Netlify Forms kullanabilirsiniz.

S: Resimler gösterilmiyor?
C: Resim dosyalarını images/ klasörüne ekleyin.
   HTML'de şekilde yolu güncelleyin: src="images/photo.jpg"

S: CSS yüklenmemiyor?
C: Cache temizleyin (Ctrl+Shift+Delete) veya
   Ctrl+F5 ile hard refresh yapın.

S: Mobilte görüntüleri kötü?
C: Viewport meta tag kontrol edin:
   <meta name="viewport" content="width=device-width, initial-scale=1.0">

S: Font gösterilmiyor?
C: CDN linkini kontrol edin. Google Fonts dosya
   yolları doğru mu diye kontrol edin.
