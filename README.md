# Portfolio Web Sayfası

Modern ve responsive tasarıma sahip, tamamen statik bir portfolio web sayfası.

## 🚀 Başlangıç

Lütfen `portfolio-project/` klasöründeki **QUICKSTART.md** dosyasını okuyun.

## 📁 Proje Yapısı

```
onurazbar.github.io/
└── portfolio-project/          ← Portfolio web sayfası
    ├── index.html              ← Ana sayfa
    ├── css/style.css           ← Stiller
    ├── js/script.js            ← JavaScript
    ├── data/projects.json      ← Proje verisi
    ├── README.md               ← Kapsamlı dokümantasyon
    ├── QUICKSTART.md           ← Hızlı başlangıç
    └── LICENSE                 ← MIT Lisansı
```

## 🎯 İçerik

- Navigation Bar (Fixed navbar + Hamburger menü)
- Hero Section (Başlık ve CTA butonları)
- About Section (Kişisel bilgi + istatistikler)
- Projects Section (6 proje kartı)
- Skills Section (Yetenekler + progress barlar)
- Contact Section (Form + iletişim)
- Footer (Telif hakkı + sosyal linkler)

## ✨ Özellikler

- ✅ Responsive tasarım (320px - 2560px)
- ✅ Modern UI (Gradient, animasyon, smooth scroll)
- ✅ Vanilla JavaScript (Form validasyonu, menü)
- ✅ SEO uyumlu (Meta tags, semantic HTML)
- ✅ Erişilebilir (WCAG 2.1 AA)
- ✅ Statik HTML/CSS/JS (Sunucu gerekmez)

## 🌐 Dağıtım

```bash
# GitHub Pages
git push origin main

# Netlify - Drag and drop

```
